# JMDT: The Truth Layer 
--

Jupiter Meta Data Token (JMDT) is the native utility token powering Truth Layer, Jupiter Meta Labs' enterprise-grade decentralized data and identity infrastructure built for trusted, privacy-preserving enterprise applications. JMDT powers and secures the ecosystem's flagship decentralized applications, including SuperJ, Hercules, and Poseidon, which collectively serve an ecosystem of over 20 million users and more than 40 enterprise customers. The token facilitates decentralized identity, enterprise data processing, Layer 2 execution, and network validation across the Truth Layer.

The network is built on a multi-layer architecture. Layer 2 provides state execution within the RISC Zero zkVM, using a zero-knowledge (STARK) design for scalable computation. Finalized state commitments are anchored to Ethereum Layer 1 through gas-optimized settlement, combining high throughput with Ethereum-grade security. A high-performance Layer 3 Directed Acyclic Graph (DAG), designed for fast, localized enterprise workloads, is being introduced to further scale the network.

JMDT employs Asynchronous Validation Consensus (AVC), using Verifiable Random Function (VRF)-based validator selection to decentralize block validation and strengthen network security. Finalized transactions are recorded in an immutable, append-only ledger, ensuring transparent, tamper-evident, and auditable records for enterprise applications.

JMDT is hard capped at 1 billion tokens, with a current circulating supply of 250 million tokens. As the ecosystem's native utility asset, it is used for transaction fees, Layer 2 rollup execution, network validation, and decentralized identity operations.

Privacy and compliance are foundational to the Truth Layer. The ecosystem natively supports W3C Decentralized Identifiers (DIDs), enabling identity verification to occur locally on users' devices without exposing or storing personally identifiable information (PII) on-chain. This privacy-preserving architecture is designed to support regulatory frameworks including GDPR and HIPAA.
